# Make the AI judge feel curious

A short text (272 characters) written to intrigue the AI judge reading it:
an envelope with no stamp, a warning about a blue door, and a clock that
is slowing down. `main.py` (Python 3.13, standard library only) writes it
to `/output/entry.txt`, deterministically, on every run.
